# Master recovery index and Journey Studio

The new studio is in [`dist/journey-studio`](dist/journey-studio). The master library home page links to it.

Audit: 2026-09-18. All **1,088 original archive files in 130 collections** matched the master index by exact Git blob SHA. Missing: **0**. Changed hashes: **0**. See the [machine-readable recovery report](dist/journey-studio/recovery-report.json).

There are **18,569 main catalog source placements**, including **12,787 with subtitles** and **5,782 without subtitles**. The studio also exposes **48,626 supplementary/history placements** and **3,000 additional journey concepts**. Counts describe source placements, not unique titles or completed manuscripts. Original wording and source locators are preserved. Held and reference records are excluded from drafting.

The Pastor/Advisor studio supports **21, 30 and 40 days**, editing, JSON backup/restore, Markdown and print HTML downloads, and browser PDF printing. It uses an original guided devotional framework with Scripture, a biblical scene, teaching, a point to ponder, daily practice, three questions, prayer and a next step. Pasted source notes are preserved separately. Source-specific authored manuscripts and AI adaptation are not claimed.

The Master Plan is the architecture behind the formation sequence, not a finished generator: timeless truth → timely interpretation → personal application → specific next step → ongoing formation → outward service.

Validation: 36 duration/audience/focus scenarios; title and restriction preservation; malicious-text escaping; backup schema validation; UI catalog selection, generation, edit/export, advisor language and source-index download. A 40-day print specimen rendered to 49 pages with all 40 days present and no blank pages. Source content is still subject to editorial, scriptural and permissions review before distribution.
